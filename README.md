# StickerCountApp

シールが貼ってあるアンケートパネルを撮影すると、シールを自動で数えて記録するアプリ

## 作った動機
カンファレンスでブース出展をした際に、ブースにシール貼り付け式のアンケートパネルを置くことが度々ある。パネルに貼られたシール数＝ブースに来訪した人の数として報告するため、毎回協賛終わりには300枚ほどのシールを5分程度かけて手作業で数えていて手間がかかっていた。そのためアプリを使ってその手間を簡略化したくてこのアプリを作った。

## 学んだこと(開発の流れ)
* 白いパネルと明るさが近い淡色シールが輪郭検出から漏れていると考え、シールを白、背景を黒とする彩度マスクを実施。 当初の不足データはトリミングの座標計算にバグがあり、意図と違う場所を切り抜いていた影響と判明。仮説の根拠となるデータが確実に正しいものであるかを確認することの大切さを学んだ。修正後に再検証、淡色シールの未検出を改めて確認した。
* enumを使って状態遷移を管理することで、case crop(UIImage)のように各画面に必要なデータを一緒に管理できるようにした。これにより定義をenumに集約できるので、保守性が上がったと思われる。

## 精度の検証と改善
* Visionを使ってシールの輪郭を検出することでシールの枚数を数えることを試したが、二つ課題があった。画像によってシールのサイズがまちまち画像に対する割合が一貫しないため、サイズの問題は、トリミングの指示書きを修正し、一定の改善が行えた(指示を直す前は約−16%、直した後は約−4〜−9%)。もう一つはシールの色が多岐に渡り背景の白と判別がつかないことだが、これについては後述するピクセル操作で改善した
* ピクセルごとにRGBの最大値と最小値の差が60以上だった場合はシールとして白に変換し、背景は黒とすることで、シールとしての判定を容易にした。Visionと比較して、慎重にトリミングした場合、おおよそ検出精度は-26%から+2.7%まで改善した（上述した−4〜−9%は指示書きどおりに調整した場合）。それでも画像に対するシールの割合が一貫しないため、結果の正確性に難が残っていると考える
